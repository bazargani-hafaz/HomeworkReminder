# 📚 یادآور مشق — نسخه ۱

اپ فارسی، آفلاین و مدرن برای ثبت و یادآوری تکالیف مدرسه.

## امکانات
- رابط کاربری مدرن و Dark
- راست‌چین و فارسی
- افزودن درس و تکلیف
- انتخاب تاریخ و ساعت یادآوری
- ذخیره اطلاعات روی گوشی
- اعلان یادآوری
- علامت‌گذاری تکلیف به‌عنوان انجام‌شده
- نوار پیشرفت
- بخش تکالیف باقی‌مانده و انجام‌شده

## ساخت APK بدون Android Studio
این پروژه یک GitHub Actions دارد که با هر Push به `main` یا اجرای دستی، APK دیباگ را می‌سازد و به‌صورت Artifact در اختیار قرار می‌دهد.

مسیر فایل خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## اجرای Build دستی
در GitHub وارد تب **Actions** شو، Workflow با نام **Build APK** را باز کن و **Run workflow** را بزن.

برای Android 13 و بالاتر، اپ در اجرای اول مجوز اعلان می‌خواهد.
